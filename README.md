# 💳 Credit Card Fraud Detection System

A production-style, modular machine learning application for detecting fraudulent credit card transactions. Includes a training pipeline, FastAPI backend, Streamlit dashboard, and test suite.

## 🎯 Overview

This application provides:
- **Modular ML pipeline** (`app/ml/`) — schema, validation, preprocessing, training, prediction
- **FastAPI backend** (`app/api/`) — REST API for predictions
- **Streamlit dashboard** (`streamlit_app.py`) — interactive web UI
- **Test suite** (`tests/`) — unit and integration tests

The model is selected automatically from Logistic Regression, Random Forest, and XGBoost based on validation F1-score, with threshold tuning on a held-out validation split.

## ✨ Features

- **🔍 Real-time Fraud Detection**: Instant prediction with probability scores and risk categories
- **📊 Interactive Data Visualization**: Comprehensive dataset analysis with Plotly charts
- **🎛️ User-friendly Interface**: Clean, intuitive Streamlit interface
- **📈 Real Model Metrics**: All metrics loaded from `artifacts/metrics.json` (no hardcoded values)
- **🛡️ Risk Assessment**: Low / Medium / High risk categorization
- **📋 Sample Data**: Quick access to legitimate and fraudulent transaction samples
- **🔌 REST API**: FastAPI backend with `/predict`, `/predict/batch`, `/model/info` endpoints
- **🧪 Test Suite**: 22 tests covering validation, prediction, and API

## 🚀 Quick Start

### Prerequisites

- Python 3.10 or higher
- pip package manager

### Installation

1. **Clone or download the project files**
   ```bash
   # Ensure you have these files in your directory:
   # - creditcard.csv
   # - requirements.txt
   # - app/ (package)
   # - streamlit_app.py
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Train the model** (generates `artifacts/`)
   ```bash
   python -m app.ml.training
   ```

4. **Run the Streamlit dashboard**
   ```bash
   streamlit run streamlit_app.py
   ```

5. **Or run the FastAPI backend**
   ```bash
   python -m uvicorn app.api.main:app --reload
   ```
   Then open `http://127.0.0.1:8000/docs` for interactive API docs.


```bash
python -m pytest tests/ -v
```

## 🔧 Model Details

### Algorithm
- **Selected model**: Determined automatically during training (best validation F1)
- **Candidates**: Logistic Regression, Random Forest, XGBoost
- **SMOTE** for handling class imbalance (training split only)
- **StandardScaler** for `Time` and `Amount` features
- **Threshold tuning** on validation split (F1 maximization)

### Performance Metrics (Test Set)
Metrics are stored in `artifacts/metrics.json` after training. See the file for current values.

### Features
- **30 anonymized features** (V1-V28, Time, Amount)
- **Time**: Seconds elapsed since first transaction
- **Amount**: Transaction amount
- **V1-V28**: PCA-transformed features (anonymized for privacy)

## 🛠️ Technical Stack

- **Frontend**: Streamlit
- **Backend**: FastAPI, Uvicorn
- **Machine Learning**: Scikit-learn, XGBoost, imbalanced-learn (SMOTE)
- **Data Processing**: Pandas, NumPy
- **Visualization**: Plotly
- **Model Persistence**: Joblib
- **Testing**: pytest

## 📊 Dataset Information

- **Total Transactions**: 284,807 (283,726 after deduplication)
- **Fraudulent Transactions**: ~473 (0.17%)
- **Legitimate Transactions**: ~283,253 (99.83%)
- **Features**: 30 (28 PCA components + Time + Amount)
- **Duplicates removed**: 1,081 rows
